# Day 1：初始化双前端工程

## 目标与产出

- 建立 client 与 admin 两个 Vue 3 工程。
- 配置 Element Plus、Vue Router、Vuex 和 Axios。
- 客户端使用 Mock 数据。
- 客户端端口为 8787，管理端端口为 8788。

## 验收

- client 和 admin 都能执行 `npm run serve`。
- 两个首页都能正常显示。
- 浏览器控制台没有阻断性错误。
